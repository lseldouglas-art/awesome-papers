# Community Code of Conduct

We want this project to be rigorous, welcoming, and safe for contributors across disciplines and levels of experience.

## Expected behavior

- Critique claims, methods, and code without attacking people.
- State uncertainty and distinguish evidence from opinion.
- Respect privacy, authorship, source licenses, and research participants.
- Make review feedback specific, actionable, and proportionate.
- Correct mistakes openly without erasing the record that a correction occurred.

## Unacceptable behavior

Harassment, discrimination, intimidation, doxxing, sexualized conduct, deliberate misrepresentation of evidence, plagiarism, credential exposure, and publication of private research material are not tolerated.

## Enforcement

Report conduct concerns privately to the repository owner through their GitHub profile. Maintainers may edit or remove contributions, lock discussions, or restrict participation when necessary to protect the community.
