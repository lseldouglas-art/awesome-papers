## 本轮结果与验收口径

用户指出：原页面上方只有少量图文，下方高质量报告仍是大段文字；要求至少减少50%的阅读文字，并把下方内容转成图文。根因有两处：原图解仅覆盖少量研究主线；目录跳转会打开完整文字区域的所有折叠祖先。

现在九章都在同一阅读页中连续出现，目录定位对应图解；原文按章节在独立阅读窗口打开。完整文字报告仍可主动切换阅读，不再与整套图解同时铺开。新版领域阅读偏好独立初始化为图解，避免旧版“完整阅读”设置让升级后的首次体验仍是长报告。其他研究阶段的图表、目录、完整阅读行为保持原有路由。

## 九章分别怎样表达

| 章节 | 本轮采用的图文结构 | 可继续做的事 |
| --- | --- | --- |
| 领域概览 | 研究对象与实际问题分布图 | 点击问题查看所在原文 |

| 主要分支与发现 | 复用研究样本、机制分支、成像配对示意；主线与其他分支可切换 | 查看具体研究与分支综合判断 |
| 当前热点 | 原文明确提出的问题变化、方向关系及待验证条件 | 回查各项引文与完整解释 |
| 关键争议 | 发现与对照／条件并排；可比结局、方法、暴露分开 | 切换问题并核对完整命题 |
| 技术与方法演进 | 方法 → 能回答的问题 | 按行查看原文、适用条件与来源 |

| 研究成熟度 | 按研究分支展示报告中的证据状态 | 查看原有判断及访问边界 |
| 后续研究方向 | 从关注问题展开分支路径 | 选择方向后进入原检索流程 |

图中文字采用已存内容的确定性提取及节选；省略处明确标记。数值、否定词、已报告／未报告、科学推论及访问层级仍由原记录约束。材料不足的历史不补造转折；不同暴露的结果不会自动画成相互冲突；未知人体验证不改成已证实“没有验证”。

## 原文和依据怎样保留

- 每章提供“原文与依据”，显示该章所有保存段落、原有标题、材料边界和引用定位。
- 引文复用原来源面板，批注继续关联原段落；打开原文时固定所选研究结果版本。
- “阅读完整文字报告”保留全文阅读；“返回完整领域图解”恢复图文。
- 不改写已保存报告，不新增科学采纳决定，不生成实验结果，不重跑文献或模型分析。
- 补材料只打开原有准备界面，研究者仍可检查和修改后再运行。

## 当前边界与下一步

这是领域结果阅读方式的改进，未重新评价既有科研结论，也未证明工作台比GPT科研更有效。确定性节选可能省略原报告细节；完整命题和条件始终可按节回查。运行时按内容自动检索开放配图或生成写实图片的D-054方向仍待独立实施；本轮主要增加承载结果关系的图解，复用已有插画素材。

现有构建仍提示主包较大；本轮未新增依赖，也未把生产构建通过称为全面性能或无障碍审计通过。下一步是研究者刷新原课题，从概览一路阅读到研究方向，判断哪些图解仍需调整，再按既有P0方案接续真实同题比较。
