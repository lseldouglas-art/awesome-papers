# v0.34.3：Ponytail 升级交付与 Claude Agent 试点

本轮先改善长任务可靠性，再把 Claude Agent SDK 接到现有选题比较和方案研判。成果画布、研究内核、版本、采用、引用快照和任务恢复继续由工作台维护。SDK 试点默认关闭。

## 实际交付

| 目标 | 实现 | 验证边界 |
| --- | --- | --- |
| 中断后不整批重做 | 保存已收到正文和用量，独立校验单篇，容量耗尽时拆分剩余材料 | 合成截断、局部失败与接续覆盖通过；真实供应商长批次尚未重跑 |
| 解决引用格式错位 | 统一 R/P 定位，兼容唯一精确的旧摘录，记录转换依据 | 不接受未知段落、模糊匹配、省略文本或跨来源编号 |
| 小而明确的输出契约 | Ajv 校验逐篇整理和研判阶段，原始输出先保存 | 结构与定位通过不等于科研结论成立 |
| 替换推理运行方式 | SDK 仅承接候选比较及初判、质疑、修订；逐篇处理和 PubMed 仍复用现有实现 | 默认关闭，无供应商自动切换，无双重研究循环 |
| 限定材料与工具 | 两个只读工具：列出已选材料、读取快照及 P 编号 | 实际 SDK 原生进程对本机模拟服务验证通过 |
| 避免开发规则混入研究 | 独立运行目录、独立配置目录、禁用用户／项目 settings 加载、自动记忆、持久 SDK 会话和通用工具 | 不读取根 AGENTS.md／CLAUDE.md 作为科研提示；受宿主管理策略约束 |
| 让反方意见有用 | 质疑指向具体主张与证据，修订时再次检查质疑本身是否成立 | 采用审稿原则，科学质量仍待真实案例评价 |
| 记录真实运行信息 | 保存运行模型、档位、材料读取、SDK 轮次及用量；设置变化阻止沿用旧运行重试 | SDK 物理请求数不可完全观察，记为未知；费用估计不冒充账单 |

## 接入结构

```text
现有画布／科研搭档
    → 现有任务与准确输入版本
        → 常规模型适配器：逐篇整理、其余现有任务
        → 可选 Claude Agent SDK：候选比较、三段研判
            → 本轮材料目录／原文快照（只读）
    → 原始输出记录 → 字段、引用、覆盖与科研对象校验
    → 原有候选成果／方案草案 → 用户明确采用
```

外部补检仍沿用原有检索范围与访问快照逻辑。SDK 不能访问任意文件、运行终端命令、发起任意网络工具、修改数据库或采用研究方案。失败后不会静默改用另一家模型。

## 默认关闭与启用方式

普通启动无需额外配置。API 的 `agentPilot.enabled` 为 false，所有原有路径继续使用常规模型配置。

如需开展后续受控试用，在实际 `RW_DEMO_DATA_DIR` 内单独保存 `agent-runtime-private.json`，权限设为仅本人可读写，然后重启本机服务。例如：

```json
{
  "enabled": false,
  "baseUrl": "https://由你确认的Anthropic兼容服务地址",
  "model": "由该服务确认支持的模型",
  "apiKey": "在本机填写",
  "effort": "high",
  "maxTurns": 8
}
```

明确完成服务、模型及材料范围选择后，才把 enabled 改为 true。该文件保持在私有数据目录，不提交、不导出。模型设置页会显示试点实际模型与档位；原思考控件继续控制常规路径，试点使用独立配置。关闭时改回 false 并重启，不迁移研究数据。

OpenAI Chat Completions 地址不能直接当作 Anthropic 兼容地址。没有自动复用、转换或发送现有私有密钥与材料。兼容服务是否支持 SDK 的工具、结构化输出和思考参数，须逐服务验证。本轮未启用真实服务。

## 验证

- 382 项完整隔离回归通过，覆盖旧研究流程、SDK 路由、只读材料边界、取消、超时、错误脱敏、长文献重复片段去重和配置变更后的重试约束。
- 桌面 1365×1000、手机 390×844 检查批次设为 12 并保存，模型保持禁用，新增模型调用为零。
- 使用真实 SDK 0.3.278／Claude Code 2.1.278 原生进程，对本机 Anthropic 模拟服务完成读取工具与结构化输出。模拟服务收到 2 次生成请求；无付费模型调用。
- `npm test` 为隔离回归；`npm run build` 构建前端；`npm run test:agent-smoke` 运行真实 SDK 到本机模拟服务的独立检查。后者只使用合成数据和假密钥，日志留在临时目录。
- 未重发私人研究资料，未执行真实科研质量对照。用户原有模型、数据和已采用决定不因安装 SDK 改变。

## 选择性复用与来源

| 来源 | 实际采用 | 保留边界 |
| --- | --- | --- |
| [Claude Agent SDK](https://github.com/anthropics/claude-agent-sdk-typescript) | 固定版本依赖、进程与工具接口、结构化输出 | 遵循该包自己的许可；没有把它标为 MIT 开源内核 |

| [SDK 结构化输出](https://code.claude.com/docs/en/agent-sdk/structured-outputs) | 为研判阶段传 schema 并接收 structured_output | 仍可能达到重试上限；继续由工作台校验 |
| [Open Science](https://github.com/ai4s-research/open-science) | 借鉴运行时与产品界面分离、可追溯阅读的思路 | 未复制其 OpenCode 协议、状态库或桌面壳 |
| [DeepReviewer-v2](https://github.com/ResearAI/DeepReviewer-v2) | 借鉴有原文依据的质疑及对质疑再次检查 | 未复制整套提示、固定批注数或评分机制 |
| [OpenAI4S 架构](https://github.com/PKU-YuanGroup/OpenAI4S/blob/main/docs/architecture.md) | 借鉴编排与科学执行分开的边界 | 本轮保持 Node 内核，不新增 Python 执行平台 |
