# 科研工作台 v2.0 · 完整个人 Demo

当前版本 v0.8.0；状态及验收证据统一见 [当前断点](../断点续作.md) 和 [v0.8 交互与图解记录](../交互指引与图解阅读-v0.8.md)。

## 启动

在 `research-workbench-v2.0` 目录，使用 Node 22.23.1 或兼容更新版本：

```sh
npm ci
npm run build
npm start
```

本机已配置 **http://127.0.0.1:4320**。私有 `.env` 将 `RW_DEMO_DATA_DIR` 指向 `demo-api/.local/demo-v0.6-complete-20260908`，`npm start` 会继续同一份数据。无环境覆盖时默认端口是 4318，默认数据目录是 `demo-api/.local`。开发用 `npm run dev`；先停止同一目录的另一个服务再启动。

体验库沿用 5 个旧课题副本、两个公开案例以及用户后来创建的课题；禁止按历史固定课题数量回灌或覆盖当前库。原 4318 服务与原 JSON 均保留；后续在 4320 的修改保存到新 SQLite，不自动回写原库。

依赖已经独立锁定：React 19.2.8、Vite 7.3.6、better-sqlite3 13.0.3。本机 Node 22.23.1 已验证完整安装、原生驱动加载及生产构建。不是跨平台安装或多人部署验收。

## 可以体验的主线

默认图解优先，顶部显示位置与下一步。选题对照图可直接进入独立论证页；点击“进入已选题目 · 下一步”或输入“进入下一步”不会重复调用模型。完整依据按需展开，已有论证继续核查依据。新构建会提示“保存并更新界面”，请用它更新长期打开的标签页。

表达意图 → 解释范围 → 检索并查看／选择材料 → 逐篇整理及领域认识 → 追问或深入 → 比较问题 → 深入、保留、采用、排除或未决 → 课题工作简报 → 重开接续与改题影响。

左侧研究脉络保留来路、选题比较与各探索分支；点击题目进入独立页面，返回上一步或查看当时来源版本。领域页面提供研究地图、发展脉络与证据分布；论文工作题目附拟议设计和创新性核查，不能保证发表分区。中央顶部也可切换成果。用户选择和成果内容版本分开保存；采用的问题修订后，原采用版本保持，改选须明确操作。根据当前取舍更新简报时保留旧版本。历史恢复也不会暗中恢复或撤销用户决定。

## 材料、范围与模型

PubMed 初步扫描按相关性与发表时间各取前 20 条，去重后返回题名／摘要；页面保留这一检索范围，不声称是完整综述。题名、摘要、片段和全文访问分别标注，未报告不能写成未实施。

完整处理本次所选材料；没有任意材料数量、输入字符或调用次数限制。只有配置了服务商的真实输入额度，才以完整分批方式整理，记录分段覆盖及成功检查点。即使提取后的完整综合仍超出能力，也会清楚失败并保留材料，不默默省略文章。未知服务商限制不假装已知。

模型配置在页面左下角。本机私有文件保存兼容服务地址、模型与密钥；密钥不入项目、浏览器缓存、导出或 Git。每次运行记录材料范围、尝试、工具与模型调用、版本／输入指纹、用量及未知费用。超时或中断不自动重发；用户触发重试可复用已完成的提取。

## 可靠保存与迁移

- 主存储是 `workspace.sqlite`，SQLite 事务提交业务修改、版本、事件和回执；不可变历史行由应用与数据库共同保护。
- 首次发现 schema 1/2 `workspace.json` 时保留原字节备份，事务导入并核对；损坏时停止，不自动创建空课题。
- 旧 JSON 后来又被旧应用写入时，重新打开 SQLite 会拒绝静默继续；必须先核对两边的实际变化。
- 正常关闭释放写锁；崩溃重启只回收已确认不存在 PID 的锁。活动 PID、权限异常及损坏锁不擅自解除。并发恢复由原生事务保护。
- 本机受信程序可用 `store.backup(destination)` 创建一致 SQLite 副本，用 `store.exportSnapshot(destination)` 导出完整工作区 JSON；目标必须为新文件，不能直接覆盖备份。
- 恢复备份时先停止此数据目录的服务，使用新的数据目录启动副本并核对。不要删除旧目录或版本。
- 浏览器暂存未提交个人认识、未发送交流与未确认开始请求；清除浏览器数据会移除这些临时副本。服务确认后数据以数据库为准。

## 网络与验证

根目录启动脚本使用 `.env` 和 Node 环境代理功能。`.env` 中的 HTTP_PROXY、HTTPS_PROXY、ALL_PROXY 传给子进程，NO_PROXY 包含 localhost、127.0.0.1、::1。本机代理端口取已配置值，不在代码中暗定；模型密钥继续只用私有模型设置。

```sh
npm test
npm run build
```

浏览器脚本 `scripts/browser-regression.mjs` 使用明确的工程夹具、独立端口和数据目录；测试数据不是科研证据。公开材料真实体验另记，不能把程序引用定位、AI 整理或工程通过写成人工科研核验。本人本机 Demo 不等于多人上线。
