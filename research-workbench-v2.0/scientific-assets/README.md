## 内容与导入

- `manifest.json`：版本、类别、中英文检索词、文件路径、作者、来源、逐项许可、原始哈希、尺寸、审阅状态。
- `files/`：原始 SVG 与 PNG。没有用生成图片冒充矢量素材。
- `licenses/`：本批开放素材对应的原始许可文件。
- `generation-prompts.json`：三项生成素材的原始提示、一次幽门螺杆菌清晰化修改；共四次 built-in Image Generator 调用，工具未报告模型版本、用量或费用。
- 工作台后台直接读取本目录，`GET /api/scientific-assets` 提供索引，`GET /api/scientific-assets/{id}` 读取素材，`GET /api/scientific-assets/pack` 下载 ZIP。包内解压顶层目录即 `scientific-assets`，部署时保留结构与文件，不把图像写入每个课题数据库。
- 后台只按目录中已登记 ID 取文件，不接受用户给定的任意文件路径或外链。

## 原始素材与授权

开放素材来自 [Bioicons](https://github.com/duerrsimon/bioicons)，固定提交 `d29e766ea7580b8063c4f47b29e872db40a4d979`；本次读取实际公开索引 2,804 项，精选 49 项，未镜像整站。

47 项 Servier 作品沿用 **该固定 Bioicons 分发项标明的 CC BY 3.0**，2 项社区素材为 CC0。Servier 当前官网采用 CC BY 4.0，但本包不擅自改写原始分发项的许可。原图文件保持不变；工作台可缩放、翻转和组装，导出的署名需结合实际修改进一步注明。

生成素材没有伪造 CC0/MIT 授权，记录为 AI-generated。它们经外观检查但未经独立医学专家审稿，也不自动获得任何目标期刊的使用许可。投稿时按期刊政策决定使用与披露，不能作为显微照片、病理图、实验结果或观察记录。

## 调研和 Ponytail 应用

- [Ponytail 核心方法](https://github.com/DietrichGebert/ponytail/blob/main/skills/ponytail/SKILL.md)：先理解路径、检查现有实现、优先原生平台和已有依赖。本次复用 SVG、既有版本/任务/模型调用记录，没有另装绘图 MCP 或新增画布服务。
- [Bioicons 官方说明](https://github.com/duerrsimon/bioicons/blob/main/README.md)：开放 SVG，逐项署名与许可；适合作为主要接入源。
- [Servier Medical Art](https://smart.servier.com/) 及[署名说明](https://smart.servier.com/how-to-cite-servier-medical-art/)：医学主题覆盖广，作为本批统一风格的主要作者来源。
- [NIH BioArt](https://bioart.niaid.nih.gov/)、[具体条目许可要求](https://bioart.niaid.nih.gov/terms)：可作专业补充源；本批未下载其素材，不把整站自动视为公共领域。

优化发生在使用层：中文归类与检索、同源风格筛选、准确来源、署名导出、可编辑组装、缺口按需生成。没有重描或抹去第三方署名，没有把已有素材全部重新生图。
