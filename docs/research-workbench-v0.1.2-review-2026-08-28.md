P0 与 P1 的测试不变量已经闭合。最终只读审查未发现新的发布阻断项，也未发现声明边界内的明显科研逻辑错误或证据链破坏。该版本可以作为本地单研究者 Alpha 发布候选，但不能替代指南、全文核查、正式系统综述或临床判断。

## P1：研究者报告与产品流程

报告重构为四章：

1. **领域图景**：从临床决策最小单元解释领域现状、具体问题和新手判断点。
2. **近五年趋势与选题分析**：只分析当前样本的主题、年份、题名和期刊结构，不把等额抽样解释为发文增长。
3. **一句话总结与研究机会**：提供 5 个结构化候选，逐一给出待核假设、可验证增量与放弃条件。
4. **综述方向**：只展开当前选择的一个方向，给出范围、PICO/PCC、文献组织、工作量、周期与降级条件。

每章一个主动作、一个证据入口；代表性证据最多 8 条，完整 20 条纳入账本单独保留。PMID 没有删除，而是从内容墙移到需要时可追溯的位置。

## 三视角复核

### 博士生导师

报告已经能稳定区分“样本直接观察”“研究机会推断”“外部综述待核查”。候选题目包含人群、疾病阶段、比较、患者重要结局、验证层级和放弃条件，适合用于立题前的导师讨论。它仍不是正式系统综述方案；数据库范围、双人筛选、全文获取、偏倚评价和统计方法要在立题后冻结。

### 钟教授方法线

当前流程实现了问题优先、证据可定位、未知保留、结论强度受访问层级约束，以及关键决策由研究者确认。系统不再把低频当空白、把摘要未报告当未实施、把自一致哈希当防篡改证明，也不让外部调用方伪造已核查状态。

### 产品经理

文字简报成为主线，可视化只承担结构比较；四章降低单屏密度，并把“理解领域—比较机会—选择方向—开始窄检索”组织成连续决策流。PMID 与完整账本按需展开，避免证据链压过研究判断。下一阶段的核心产品缺口已从信息架构转向真实的方向级外部核验与恢复能力。

## 仍然诚实保留的 P2

- 尚无真实方向级同题综述核查回执，也未自动生成同题综述重叠矩阵和排除综述后的原始研究量估计。
- XML 回放保留完整摘要文本，但尚未保留 `AbstractText Label` 的 OBJECTIVE/METHODS/CONCLUSIONS 段落标签；publication type 也尚未进入夹具合同。
- 当前仓库保留 EFetch 内容回放与冻结账本，没有五个窗口的独立 ESearch 选择回执；因此可以核验 20 条内容和分类，不能把“当日 Best Match 前四”描述成可独立重演的排名证明。
- 10–12 周目标尚未绑定双人筛选、数据库数量、全文获取和去重率等人员假设。
- 证据抽屉已覆盖主要主张，但还没有把“具体主张 → PMID → 摘要原句”做成显式三列表格。
- 客户端尚未独立重算报告内容指纹；第二轮临时状态的跨重启恢复仍可加强。

这些项目不破坏当前 Alpha 的声明边界，但应作为下一轮外部验证与正式研究执行能力的优先工作。
