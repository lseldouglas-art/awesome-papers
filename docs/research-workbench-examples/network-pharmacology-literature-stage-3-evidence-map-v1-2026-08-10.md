# 13篇候选文献证据地图：哪些环节已经做到，哪些仍然断开

更新日期：2026-08-10

## 这张图怎样读

这13篇论文是为了寻找“真实成分到达 - 具体靶点作用 - 靶点介导 - 疾病表型”而主动富集出的高相关候选，并不是从全部网络药理学论文中随机抽样。因此，下表的篇数只能说明这批候选的核查结果，不能估计整个领域的比例。

- `支持`：本轮实际取得的材料中有可核查结果；
- `部分`：作者报告了相关实验，但仍缺关键参数、特异性或体系对齐；
- `未知`：摘要提到方法，却没有报告足够结果；大范围筛选时保留为未知，不要求补全文，只有要判断关键细节或更强机制结论时才升级全文核查；
- `没有`：实际材料没有报告该环节，或只有分子对接、通路富集、表达变化等不能替代该环节的结果。

本轮实际取得并核查了3篇全文及补充材料；其余10篇在本轮没有实际取得并读到完整正文，因此严格停在摘要级。其中 PMID 42173417 虽被出版方标注为开放获取，本轮仍未成功取得正文文件。

## 先给总判断

1. 三篇全文中，只有槲皮素-SLC15A2研究提供了可复核的纯化蛋白 SPR 结合结果；另两篇分别停在“对接预测”或“复杂含药血清改变蛋白稳定性”。
2. 三篇全文都没有确认“明确成分在疾病组织达到有效浓度，并经特定靶点导致动物表型”。
3. 槲皮素-SLC15A2研究提供了细胞参与线索，但只有一条 siRNA、每组3个点、无回补和正式交互检验；动物中没有槲皮素单药或 SLC15A2干预。论文所报的结构编号 PDB 6VK3 与 RCSB 官方记录矛盾，而真实计算输入没有公开，因此计算部分在澄清前不可作为证据。
4. 连翁颗粒论文的 CETSA/DARTS 测试对象是完整含药血清，siRNA实验又缺少“药物 + STAT3敲低”组，不能定位直接结合成分，也不能证明药效依赖 STAT3。
5. 其余7篇摘要报告使用 SPR、CETSA 或 DARTS 等方法，但在本轮未取得全文时，只能记为“作者报告的待核查线索”；方法名称不能自动升级为已确认机制。

## 这13篇共同说明了什么

### 可以成立的判断

- 在这批研究中，网络药理学与血清药物化学、药代、组学和动物实验被用于把候选范围从“配方中可能存在的全部成分”缩小到“给药后实际出现的成分和疾病情境中的候选靶点”。
- SPR、CETSA、DARTS或酶活实验比单纯对接更接近真实作用，但每种方法只回答证据链的一部分；复杂血清的稳定性变化不能定位到某个单体，纯化蛋白结合也不能替代细胞占有和体内依赖。
- 在这13篇高相关候选中反复出现的断点不是“没有任何实验”，而是不同实验分别使用完整方剂、纯单体、健康动物、疾病动物、不同物种和不同浓度，最后在文字中被拼成一条连续机制。

### 不能成立的判断

- 不能说这13篇代表整个领域，也不能据此计算完整机制研究的比例；
- 不能把摘要中的 `validated` 或 `confirmed` 当作已经通过全文核查；
- 不能把对接、分子动力学、富集或表达变化写成真实靶点结合和因果介导；
- 不能从这些前临床研究推断临床疗效；
- 不能说本轮已证明某一方剂通过某一靶点发挥动物疗效。

## 若要声称“单一成分经特定靶点介导方剂的动物疾病表型”，最低需要什么

如果要写“成分X通过靶点Y改变表型Z”，至少需要在可比体系中同时做到：

1. 用可信化学方法确认X，并在疾病动物或相关组织中定量其可达浓度；
2. 用直接结合或细胞内靶点占有实验确认X确实作用于Y；
3. 用至少两种独立干预或干预加回补，证明X的效应随Y的状态改变；
4. 将实验浓度与真实暴露对齐，并在动物疾病表型中验证靶点依赖；
5. 预先说明样本量、随机化、盲法、排除规则、主要结局和多重比较处理；
6. 保存数据库版本、结构编号、参数、原始曲线和可复算输入，避免“方法名存在但实验不可重建”。
