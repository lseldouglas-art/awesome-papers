# 摘要级证据记录：复肾泄浊方与腺嘌呤诱导的慢性肾病

**文献：** Abudukelimu S 等，*Journal of Ethnopharmacology*，2026；PMID 42173417；DOI 10.1016/j.jep.2026.121784。  
**所处时期：** 文献调研第二阶段——建立可追溯文献库。  
**本次实际读到的材料：** PubMed 结构化摘要与编目数据、Elsevier 和 Crossref 开放状态元数据、期刊公开摘要页；未取得完整正文和补充材料。  
**当前身份：** 摘要级候选证据，不能作为已经完成的机制验证。

## 先给结论

这篇论文较清楚地报告了复肾泄浊方在腺嘌呤慢性肾病大鼠中的多层表型改善：肾功能、组织损伤、纤维化、炎症、氧化应激、线粒体状态和代谢指标均有变化；同时检出了大量循环中的方剂相关成分。它因此能够支持“方剂给药与该动物模型的肾脏及代谢改善相关”。

但论文摘要中的具体靶点来自网络预测和分子对接，PI3K/AKT/mTOR–HIF-1α 只表现为蛋白水平随方剂给药而变化。作者在摘要结尾也明确承认通路依赖性仍需验证。因此不能把这篇论文写成“复肾泄浊方通过直接靶向 PI3K/AKT/mTOR–HIF-1α 发挥作用”。

## 证据组件

### 1. 成分是否真实到达体内

- 作者报告在口服复肾泄浊方后检出 260 种循环相关成分，其中包括 39 种原型成分和 221 种代谢物。
- 这支持“方剂相关物质进入循环”，比直接把配方数据库中的所有成分用于网络预测更接近真实暴露。
- 摘要没有列出主要成分名称、鉴定置信度、采样时间、定量浓度、组织分布，也没有说明血清药物化学是在健康大鼠还是慢性肾病大鼠中完成。

### 2. 是否有具体成分结合或占有具体靶点

- 作者把 39 种原型成分用于网络分析和分子对接，提出 PI3K/AKT、HIF-1α 及脂质代谢等候选方向。
- 分子对接只能说明计算模型中的几何和能量相容性，不能证明真实结合、细胞内靶点占有或选择性。
- 摘要未报告 SPR、CETSA、DARTS、亲和纯化或其他直接结合/占有实验，因此这一环尚未建立。

### 3. 靶点是否介导药物效应

- 大鼠肾组织中，方剂给药与 PI3K、AKT、mTOR 磷酸化下降和 HIF-1α 表达下降同时出现。
- 摘要没有报告通路抑制剂、激动剂、基因敲低、敲除、过表达或回补实验。
- 因而这些蛋白变化是伴随关系，不能证明该通路是疗效所必需的中介。作者本人也在摘要中写明“pathway dependency remains to be validated”。

### 4. 是否有疾病相关表型

- 研究先以腺嘌呤 250 mg/kg/天连续三周建立慢性肾病模型，再把建模成功的大鼠随机分到模型组、复肾泄浊方高剂量组 32.5 g/kg/天和低剂量组 16.3 g/kg/天，治疗四周，并保留健康对照。
- 摘要报告肾指数、组织病理和纤维化改善，SCr、BUN、UA、ACR 下降；炎症因子、MDA、ROS 下降，SOD、GSH-Px、线粒体膜电位和 ATP 改善，乳酸和丙酮酸下降。
- 肾组织非靶向代谢组学还报告 32 种核心差异代谢物，涉及能量和脂质代谢。
- 这些结果支持治疗性动物实验中的表型关联，但摘要未给出每组样本量、具体效应量、盲法、排除情况和安全性，也不能外推为患者疗效。

### 5. 暴露、靶点和表型是否对齐

- 循环成分、动物肾脏表型和肾组织代谢变化均有报告，但没有把某一种已定量成分与具体靶点及动物疗效连起来。
- 39 种原型成分进入网络分析，不等于 39 种成分都到达肾组织或达到有效浓度；对接结果也没有真实结合实验承接。
- 因而目前形成的是“方剂暴露—方剂动物表型”的链条，尚未形成“具体成分—具体靶点—功能依赖—动物表型”的链条。

## 摘要能够支持的最窄结论

**可以写：** 在腺嘌呤诱导的慢性肾病大鼠中，复肾泄浊方治疗与肾功能、组织学、纤维化、炎症、氧化应激、线粒体和代谢指标改善同时出现；研究还检出了方剂相关循环成分，并观察到 PI3K/AKT/mTOR–HIF-1α 相关蛋白变化。

**暂时不能写：** 某一种入血成分已经直接结合 PI3K、AKT、mTOR 或 HIF-1α；该通路介导了方剂的肾保护效应；网络和对接筛出的成分已经被证明是有效成分；该方剂对慢性肾病患者有效。

## 全文缺失造成的关键未知

1. 循环成分的身份、定量浓度、采样时间、鉴定等级及肾组织分布；
2. 每组样本量、随机化方法、结局评估盲法、排除标准、死亡和不良反应；
3. 主要结局是否预先规定，具体效应量、变异、统计模型和多重比较处理；
4. 代谢组学每组样本量、质控、批次校正、差异筛选阈值及独立验证；
5. 网络和对接的数据库版本、筛选规则、结构准备、阴性对照和稳健性；
6. 能否用直接结合实验和通路干预把具体成分、靶点与动物表型连起来。
