# 文献调研报告：网络药理学从“候选靶点”走到“机制证据”了吗

## 目前处于什么时期

现在完成的是**文献调研阶段的第三个环节：基于上一环节建立的可追溯文献库，完成跨论文证据地图与研究判断**。

上一环节通过精准检索找到了13篇最可能同时包含“成分到达、靶点作用和疾病表型”的论文。本轮已把13篇全部写入 Zotero 候选分类，固定 PMID、题名和条目键；其中3篇实际取得全文和补充材料，并按关键图表核查，另外10篇本轮没有实际取得并读到完整正文，因此严格停在摘要级，不把作者摘要中的“已验证”直接当作我们的结论。其中一篇虽被出版方标注为开放获取，本轮仍未成功取得正文文件。

这13篇是主动寻找高证据信号得到的候选，不是随机样本。本报告可以指出这批高相关候选中反复出现的证据断点，不能用来估计整个领域中各类研究的比例。

## 这一轮最重要的结论

### 1. 目前还不能确认有任何一篇完成了连续的动物机制证明

在本轮实际取得并核查的材料中，没有一篇同时证明了以下四件事：

1. 明确成分在疾病动物的相关组织达到可测、可比的浓度；
2. 该成分在细胞或组织中确实作用于具体靶点；
3. 降低、去除或恢复该靶点时，药物效应随之改变；
4. 这条关系最终解释了动物疾病表型，而不是只解释一个体外指标。

多数论文并非“没有实验”，而是把不同实验拼在了一起：方剂在动物中有效，某个单体在纯化蛋白上能够结合，另一套细胞实验出现通路变化。只要物种、剂量、时间、组织和干预对象没有对齐，这些结果就仍是多段证据，而不是一条连续机制。

### 2. 在3篇全文中，槲皮素-SLC15A2 是最强的部分证据链，但仍不能解释方剂的动物疗效

在本轮取得全文的3篇研究中，肾康方研究提供了最接近完整的一段：给药小鼠血清中定性检出槲皮素；一种测量分子物理结合的实验报告槲皮素与重组人 SLC15A2 胞外结构域的结合值为7.5微摩尔；在肾小管细胞中降低 SLC15A2 表达后，槲皮素对两个指标的组间差异不再显著。这只表示该实验没有检出组间差异，不等于已经证明槲皮素的效应消失。

但这条链仍有决定性缺口：小鼠血液和肾组织没有槲皮素浓度，无法判断细胞使用的10–20微摩尔是否在体内可达；降低靶点表达的实验只有一种方法、每组3个点，没有用第二种独立方法重复，也没有重新补回靶点看效应能否恢复，更没有直接检验“靶点状态是否改变槲皮素效应”；动物接受的是完整方剂，动物中既没有槲皮素单药，也没有干预 SLC15A2。

全文核查还发现一个阻断复现的结构来源矛盾：论文写明用蛋白三维结构编号 PDB 6VK3 作为 SLC15A2 做分子对接和动力学模拟，但 RCSB 官方记录显示，6VK3 实际是另一种蛋白复合物，并不是 SLC15A2，分辨率也与论文所写不符。论文没有公开真实的计算输入，因此目前无法判断这是结构编号写错，还是计算实际用了错误结构。真实的蛋白结合实验可以独立保留；对接、分子动力学和结合位点解释则必须在作者澄清前排除出证据链。

### 3. 本轮全文核查显示，摘要中的“验证”可能需要明显收窄

连翁颗粒论文的摘要同时写了入血成分、蛋白稳定性实验和靶点敲低，初看很接近机制证明。全文显示，稳定性实验测试的是完整含药血清，不能指出91个候选成分中的哪一个直接结合 STAT3；靶点敲低实验也没有设置“药物 + STAT3敲低”这一关键组合，因此只说明 STAT3 参与细胞屏障调节，不能证明连翁颗粒的效应依赖 STAT3。

清肺活血方论文则较好地证明了部分方剂成分可在大鼠血浆和肺组织中检出，也观察到小鼠肺纤维化表型和单体细胞活性；但具体靶点仍主要来自网络预测与分子对接，没有直接结合和靶点干预，而且暴露、动物疗效和细胞活性分别位于大鼠、小鼠和人细胞三个体系。

这两篇全文给出的具体提醒是：方法越多，不等于机制越完整。真正决定结论强度的是各实验是否回答同一个成分、同一个靶点和同一个表型之间的关系。

### 4. 网络药理学仍然有用，但它的合理角色应当更窄

现有证据不支持把网络药理学描述为“已经阐明机制”的方法，也不支持把它整体判定为无效。在本轮调研所采用的工作流中，较稳妥的定位是：结合真实入血成分或疾病数据，帮助研究者缩小候选范围，决定下一步优先验证哪些成分和靶点。

一项针对42味药、36种成分的数据库比较研究显示，在它所测试的任务中，同一批成分放入不同数据库会得到明显不同的靶点集合；本轮逐篇核查又显示，即使加入动物、组学、对接和蛋白实验，最终结论仍可能停在多个不相连的证据片段。因而后续综述更值得回答的不是“网络药理学有没有用”，而是：**哪些实验设计能够把候选关联推进为可复核的机制证据，哪些看似高级的组合仍然无法完成这一步。**

## 目前可以怎样写

可以写：

- 不同数据库和算法会改变候选靶点，网络结果应被视为待验证假设；
- 实测入血或组织分布能够约束候选成分，但“检出”不等于达到有效浓度；
- 纯化蛋白结合、细胞内靶点作用、靶点功能干预和动物表型是不同环节，不能互相替代；
- 在本轮三篇全文中，证据链都存在明确断点；槲皮素-SLC15A2是最强的部分链条，但动物机制仍未建立；
- 更可信的研究需要让成分浓度、靶点作用、功能干预和疾病表型在可比体系中对齐。

目前不能写：

- 某个方剂已经被证明通过某个靶点产生动物或临床疗效；
- 某一种蛋白结合、蛋白稳定性、分子对接或组学方法能够单独证明靶点因果；
- 这13篇代表整个网络药理学领域，或能够计算完整机制研究所占比例；
- PubMed 可以代表中文数据库和其他语种的完整证据；
- 前临床表型能够推出患者疗效或临床用药建议。

## 这轮测试形成了什么可见结果

- Zotero 分类 `网络药理学｜可追溯文献库（候选）`：13篇题录已固定；
- [13篇证据地图](./network-pharmacology-literature-stage-3-evidence-map-v1-2026-08-10.md)：用普通语言对照“到达、作用、靶点介导、表型和体系对齐”；
- 13份逐篇证据记录：分别写明读到的材料、真实实验、能支持的最窄结论和缺失环节，其中可直接查看[肾康方与槲皮素-SLC15A2](./network-pharmacology-evidence-record-PMID41977470-v1-2026-08-10.md)、[连翁颗粒与STAT3](./network-pharmacology-evidence-record-PMID38929100-v1-2026-08-10.md)和[清肺活血方与肺纤维化](./network-pharmacology-evidence-record-PMID41970211-v1-2026-08-10.md)三篇全文核查记录；
- [Zotero候选库对照表](./network-pharmacology-traceable-library-v1-2026-08-10.md)：可核对13篇论文的 PMID、题名和 Zotero 条目；
- 3篇实际取得全文的正文、补充材料、关键图表和文件校验均已核查；
- [独立核查记录](./network-pharmacology-literature-stage-3-independent-review-v1-2026-08-10.md)：检查逐篇提炼者是否把判断写得过强，并记录所有修改是否已经关闭。

这一轮已经可以交付的是**有依据的研究判断**，还不是综述正文。下一步只有在研究者确认这份证据边界后，才适合根据各主题的实际支撑文献数量生成证据大纲；目前不应直接让模型补写论文段落。
