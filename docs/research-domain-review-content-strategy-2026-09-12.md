# 领域理解：综述内容驱动与缺口补检

日期：2026-09-12。状态：用户已明确的研究方式与设计修正；图稿已产出，运行产品尚未同步。

本补充承接用户对领域图解设计的三个更正：以历年综述的内容建立领域认识；材料缺失处能继续补充综述和代表性研究；界面直接呈现关键发现、争议和具体未知。本文件优先于上一轮以数量气泡作为总览主体的图稿说明，不修改原始历史记录。

## 1. 领域理解以什么为依据

综述承担领域认识的起点：先用概括性综述建立概念、问题与分支，再比较不同时期、不同观点与关键转折前后的综述。篇数由需要覆盖的内容与新增信息决定，不能用固定篇数、每年一篇或排名前若干篇宣称领域已经理解完整。

需要核对“何时发生了什么变化”时，沿综述引文追到代表性原始研究，分清综述发表时间、其检索／内容覆盖时间、原始研究时间和事件时间。新的综述可能回顾很早的转折；新的发表年份本身不证明新发现。不同分支可以长期并行，不强画成后一阶段淘汰前一阶段的单线进步史。

检索校准的小批量是技术执行方式，不是综述规划的完成篇数。当前专题库的校准、分页与纳排功能可以复用，但不能把“取到前20篇”作为领域认识完成条件。

## 2. 怎样按内容规划材料

每个待回答问题形成一条可追溯的内容覆盖记录：

| 内容 | 要核对什么 |
|---|---|
| 核心概念与分支 | 哪些问题属于此领域，分支如何关联，是否有遗漏 |
| 历史变化 | 先前如何解释，新增了什么证据，认识怎样被扩展或修正 |
| 关键方法 | 方法使什么问题变得可回答，条件与局限是什么 |
| 共识与分歧 | 哪个具体命题存在共同支持或不同结论，研究是否可比 |
| 尚未解决的问题 | 是本次没收集到、实际访问内容未交代，还是作者明确留下的问题 |
| 现实关联 | 新材料是否改变当前研究对象的理解或下一步选择 |

每批材料检查新增贡献、重复覆盖、关键反例和剩余缺口。多个综述引用同一原始研究时保留引用关系，不视为多份独立验证。不能以支持观点的综述占多数来投票裁决科学结论。

当主要问题和重要转折有可追溯依据、新材料主要重复、关键不同解释已检查时，向用户解释“本轮可暂时收束”和剩余边界；这不等于证明文献穷尽。用户可继续、调整范围或暂停，部分成果可保留。费用、时间、访问限制导致未完成时说明实际原因，不用固定篇数包装完成。

标题／摘要适合发现与初筛。能够从摘要回答的局部问题按摘要交付；涉及综述内部论证、历史联系或精确原始研究细节时按需读取选定综述和关键研究的相关全文。公开全文相关段落、完整全文、摘要与仅题名分别记录；不默认通读全库全文，也不把仅读摘要说成完整阅读了历年综述。

## 3. 用内容判断发展变化

变化必须描述成有内容的前后关系，例如：

- 先前的问题或解释是什么；
- 新的观察、方法或研究设计增添了什么；
- 哪项认识被扩展、限定或修正；
- 这项变化的适用范围、反例与来源是什么。

数量、年度频次、中位年份、被引量仅可作为辅助材料分布信息。不能代替这些内容判断，也不能推断成熟度、研究价值或新颖性。原数量气泡降为可选辅助视图；需要显示时仍沿用清楚的坐标与去重口径，不作为主结论。

## 4. 每个材料缺口都能继续处理

缺口须写成具体问题，而非只显示一段灰色年代：

“哪些代表性试验建立了根除治疗预防胃癌的证据？”比“材料不足”更有用。

就地入口为“补充综述与代表性研究”。展开后让用户看见：

1. 要补齐的具体问题与其对当前认识的影响；
2. 可选的历年综述、参考文献追溯得到的关键原始研究、后续引用与长期随访；
3. 保留的核心研究对象、拟放宽的次要条件、来源、检索式与时间范围；
4. “开始补充检索”及“调整补检重点”；
5. 获取后逐篇筛选，再补充当前段落的内容分析，保留原版本及未解决部分。

综述检索与原始研究检索分开构式，不能将 Review 类型限制带入代表性原始研究的检索。词群以本题必要概念组织，组内OR、组间AND、主题词和自由词结合；历史追溯需要扩大年代时明确展示，不偷偷换成更宽泛的研究对象。参考文献与后续引用仅在实际来源支持时追踪，不假称连接器具备未实现能力。

补检成功不等于缺口一定解决。没有找到、无法访问、证据仍不可比、原文仍未报告分别保留，并给出下一种可行核查方式。

## 5. 展示必须先给关键内容

每个主要区块至少直接回答“我们得到了什么认识”及“这意味着什么”，再提供方法与状态细节。

| 被否定的表达 | 修订后的表达 |
|---|---|
| 实心／空心或有报告／无报告作为主体 | 明确研究发现、研究设计、适用范围与关键缺失 |
| 材料A、材料B、是否一致 | 具体研究名／作者年份、比较命题、各自结论及差异原因 |
| 泛泛写证据不足或研究空白 | 哪个问题还没回答，当前缺什么证据，应怎样补查 |
| 通用流程说明占据简报 | 研究问题 → 具体发现 → 解释／边界 → 下一步材料 |
| 以数量判断领域成熟 | 按具体问题解释重复验证、外部适用与转化瓶颈 |

“争议”需要至少能明确指出具体命题和不同结论。只有单篇研究的局限、竞争解释或尚缺验证时，命名为“未决问题／解释待核查”，不虚构反方或两项冲突研究。

本轮图稿采用真实公开来源的有限内容作为例子：LCI研究的固定观察顺序使误报差异的归因仍需验证。该例展示如何表达未决问题，并不宣称整个AI内镜领域没有前瞻性证据。

## 6. 图形与 Agent 约束

- 主视图可以使用问题关系图、研究过程示意、内容变化对照和来源连接；数量图表退为辅助。
- Agent按实际内容选择模板、节点和重点，不为凑版式编造条目、阶段或争议。
- 陈述、引用、状态和版本复用同一事实来源；程序计算图表数值、去重及链接。
- 图像是说明材料，须区分生成示意、研究原图和真实数据图；禁止生成患者影像冒充引用论文原图。
- 完整论证与引用继续可达，来源少或有未知时照实表达；不把界面做成科研评分／批准系统。
- 当前研究对象始终保留。打开分支细节不自动采纳专题、纳排或启动检索。
